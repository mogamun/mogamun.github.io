# AI 뉴스 2026-06-05 — Claude Oceanus, 재귀적 자기 개선, GPT-5.6, Nemotron 3 Ultra

## 개요

2026년 6월 5일 AI 뉴스 라운드업. Anthropic의 Mythos 후속 Oceanus 레드팀, 재귀적 자기 개선 연구, GPT-5.6 Jewel Alpha, Nvidia Nemotron 3 Ultra, Agent Arena 벤치마크 등.

## 핵심 내용

### Claude Oceanus (Mythos 후속)

- Anthropic이 Mythos Preview 후속 모델 "Oceanus v1 Preview" 레드팀 진행 중
- 레드팀은 공개 릴리즈 ~1주일 전 시작 → 공개 임박 시사
- 중국 API 프록시를 통한 접근 재판매 혐의로 레드팀 일시 중단
- 유출된 출력: 박스 판타지 월드(제로샷, 커스텀 메시 엔진), macOS 클론(50K 토큰, 3,000행), 고품질 SVG
- 저수준 추론(low-effort reasoning)만으로 장문 소프트웨어 생성 가능
- 유출 가격: $16/M input, $80/M output

### Anthropic 재귀적 자기 개선 연구

Anthropic이 "올해 가장 중요한 AI 연구 논문"이라 평가한 내부 데이터 공개:

| 지표 | 수치 |
|------|------|
| Mythos 자율 작업 시간 | 16시간+ |
| 분기당 코드 생산성 | 8배 증가 (vs 2021-2025) |
| Claude 작성 병합 코드 비율 | 80% |
| Claude Code 성공률 변화 | 40% → 70% (Mythos 도입) |
| 인당 코드 생산 | 6개월 전 대비 3배 |
| AI 코드 품질 예측 | 1년 내 인간 코드 초과 |

핵심 주장: AI가 자신의 후속 모델 개발을 가속화하는 **재귀적 자기 개선** 경로가 현실화하고 있음.

### GPT-5.6 "Jewel Alpha"

- Codex 앱에서 포착된 체크포인트
- 추론 없이 베이스 모델만으로 SVG 생성/프론트엔드 개발에서 뛰어난 성능
- GPT-5.6과 Mythos가 Gemini의 SVG/크리에이티브 웹 개발 리드를 위협

### Nemotron 3 Ultra (Nvidia)

- 550B 파라미터 오픈 프론티어 모델, 장시간 AI 에이전트 최적화
- 5x 빠른 추론, 30% 비용 감소
- GPT-5.5 대비 품질 유사, **10배 저렴** (5¢ vs 57¢)
- OpenRouter에서 현재 무료

### Agent Arena (새 벤치마크)

- 300K+ 태스크, 2M 툴 콜, 40M 행 AI 생성 코드
- 실세계 태스크 기반: 완료율, 에러 복구, 툴 사용 평가
- 순위: 1위 GPT-5.5 high → 2위 Opus 4.7 with thinking → 3위 GPT-5.4 high

### Verification Debt

- "아무도 PR을 실제로 리뷰하지 않는다" — AI 코드 → 테스트 통과 → 승인
- PR 볼륨은 폭발했지만 리뷰 노력은 스케일하지 않음
- 이 위키의 [Verification-Driven Development](/wiki/concepts/verification-driven-development/) 개념과 직결
